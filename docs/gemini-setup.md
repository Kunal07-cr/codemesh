# Gemini Setup

By default Codaventra uses a deterministic local demo provider. To enable Gemini:

1. Create a Gemini API key in Google AI Studio or the current Google AI developer console.
2. Choose an available model from official Gemini API documentation.
3. Set:

```env
GEMINI_API_KEY=...
GEMINI_MODEL=...
```

The provider calls the Gemini `generateContent` REST endpoint with retrieved Codaventra citations. Citations are generated by Codaventra retrieval and are not assumed to be produced by the model.
