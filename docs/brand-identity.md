# Codaventra Identity

The Pathfinder mark combines an open cyan C, an interlocking violet V-shaped
code path, and a coral forward chevron. It represents navigating repository
structure and turning source evidence into the next engineering step.

## Asset

- File: `apps/web/public/brand/codaventra-pathfinder-v1.png`
- Format: square RGBA PNG with a transparent background.
- Generated using the built-in image-generation tool.
- Shared by the header, route-error screen, favicon, and touch icon.
- Keep its proportions and colors; do not stretch, recolor, or add a background.
- Brand marks are decorative beside a named link or heading. The home link
  supplies the accessible name; the image has fixed intrinsic dimensions.
- Existing repository and tool icons remain unchanged.

## Generation Prompt

Create one original flat geometric symbol for Codaventra: a bold open C-shaped
angular ribbon interlocking with a rising V-shaped code path, with a precise
outward chevron at the opening. Use cyan, violet, and a small coral accent.
Center the mark on a genuinely transparent square background with crisp broad
geometry and controlled gaps. No lettering, cube stacks, circuit boards, glow,
shadows, 3D, decorative background, or mockup.
